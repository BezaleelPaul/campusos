CampusOS

Everything Campus. One Place. — Smart College ERP (Java 21 + JavaFX + SQLite).

Full app source lives in this repo. This Pages site is the live demo hub for teachers.

Demo flow

  1. Login (student1 / faculty1 / admin)
  2. Dashboard → Attendance + calculator → Timetable → Assignments → Exams → Results → Notifications → Search → Faculty/Admin

Run it

git clone <this-repo> && cd campusos && mvn test && mvn javafx:run

Releases (portable JAR) appear under GitHub Releases after Phase 14.
