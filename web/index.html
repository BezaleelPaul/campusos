CampusOS — all 14 phases built

Smart College ERP: Java 21 + JavaFX + SQLite. Full source + releases in the repo.

2-minute demo

  1. Login student1 / password123 → Dashboard (CGPA)
  2. Attendance (need/safe calculator) → Timetable → Assignments (priority) → Exams+Results (SGPA/CGPA)
  3. Notifications (priority) → Search (Trie) → Analytics (Top-K, Dijkstra)
  4. Login faculty1 → Faculty tab: mark attendance, new assignment, enter marks
  5. Login admin → Admin tab: users

Run

git clone https://github.com/BezaleelPaul/campusos && cd campusos && mvn test && mvn javafx:run

DSA inside

PriorityQueue notifications, Trie search, Heap Top-K, Graph BFS/Dijkstra, sliding window, binary search, sorting.
