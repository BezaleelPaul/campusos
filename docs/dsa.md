# DSA in CampusOS

- ArrayList/LinkedList: timetables, histories (week lists, BFS queue)
- HashMap/HashSet: Trie nodes, graph adjacency, session/lookup sets
- PriorityQueue: NotificationService ordering + TopK heap
- TreeMap-ready: date-ordered records (results ordered by semester; swap to TreeMap in AnalyticsService as exercise)
- Trie: SearchService prefix search
- Heap Top-K: AnalyticsService.topSubjects
- Graph BFS/Dijkstra: CampusGraph campus routes
- Sorting: assignments by priority score, results ordering
- Binary search: SearchService.binarySearch on sorted codes
- Sliding window: SlidingWindow.maxWindowAvg for attendance trends
